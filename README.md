# AI Inventory Management System

## Overview

An AI-powered inventory management system designed to automate stock monitoring using computer vision and modern web technologies.

The project combines a React.js frontend, Django REST Framework backend, PostgreSQL database, and AI-based image processing to create an intelligent inventory tracking solution.

## Features

- AI-based object detection for inventory monitoring
- Automated stock tracking
- User authentication and role-based access control
- REST API based backend architecture
- Inventory dashboard and analytics
- Scalable full-stack application structure

## System Architecture

The application follows a full-stack architecture:

Frontend:
React.js handles user interaction and dashboard visualization.

Backend:
Django REST Framework provides APIs, authentication, and business logic.

Database:
PostgreSQL stores inventory data and user information.

AI Module:
Computer vision models process images and assist with automated inventory tracking.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ai-inventory-management.git

git clone https://github.com/YOUR_USERNAME/ai-inventory-management.git


```

### Backend Setup

Navigate to the backend folder:

```bash
cd backend
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the backend server:

```bash
python manage.py runserver
```

### Frontend Setup

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend application:

```bash
npm start
```
