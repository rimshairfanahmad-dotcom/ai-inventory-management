# AI Inventory Management System

## Overview

AI Inventory Management System is a full-stack application designed to automate inventory monitoring using computer vision and modern web technologies.

The system combines a React.js frontend, Django REST Framework backend, PostgreSQL database, and AI-based image processing to create an intelligent inventory tracking solution.

---

## Features

- AI-powered object detection for inventory monitoring
- Automated stock tracking
- User authentication and role-based access control
- REST API-based backend architecture
- Inventory dashboard and analytics
- Scalable full-stack application structure

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-inventory-management.git
```

### Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the backend server:

```bash
python manage.py runserver
```

### Frontend Setup

Open another terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend application:

```bash
npm start
```
